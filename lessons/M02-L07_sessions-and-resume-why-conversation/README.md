# M02-L07: Sessions and resume

Captures a session ID, resumes the session, and finds its transcript on disk. Transcripts are records: decide who can read them and how long they're kept.

## Run it
```bash
uv run python lessons/M02-L07_sessions-and-resume-why-conversation/final/sessions_demo.py
```

All data is synthetic (`data/synthetic/finance/`). Shared helpers (`MODEL`, data loaders, `show()`) come from `src/course_data`.
