# M02-L08: Model, turn and budget limits

Runs the same task with a turn limit that's too low, a budget that's too low, and sensible limits. Each limit stops the run with a distinct result subtype.

## Run it
```bash
uv run python lessons/M02-L08_model-turn-and-budget-limits-as-safety/final/limits_demo.py
```

All data is synthetic (`data/synthetic/finance/`). Shared helpers (`MODEL`, data loaders, `show()`) come from `src/course_data`.
